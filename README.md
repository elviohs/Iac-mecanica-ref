# Referencia Técnica — IAC Mecánica

Herramienta de consulta rápida para el departamento de Mecánica del [Instituto de Astrofísica de Canarias](https://www.iac.es). Funciona directamente en el navegador, sin instalación ni servidor.

🔗 **[Abrir la herramienta](https://elviohs.github.io/Iac-mecanica-ref/)**

---

## Contenido

| Sección | Qué incluye |
|---|---|
| **01 Materiales** | Calculadora de propiedades criogénicas (K, S, ΔL, E) con polinomios NIST para aceros, aluminio, cobre, Invar y otros |
| **02 Tornillos DIN 912** | Tabla de par de apriete, longitud mínima de rosca y diámetro de taladro pasante para M2–M24 en 8.8 / 10.9 / 12.9 |
| **03 Tolerancias ISO 286** | Calculadora de ajustes entre dos tolerancias (eje/agujero): desviaciones, holgura/apriete y tipo de ajuste |
| **04 Juntas Tóricas** | Selección de O-Ring Parker Serie 2-XXX y cálculo del alojamiento (L, G, R) para secciones W = 1.78 / 2.62 / 3.53 / 5.33 / 6.99 mm |
| **05 Acabado Superficial** | Calculadora de grado N (ISO 1302): Ra, Rz, RMS en µm y procesos habituales (fresado, torneado, rectificado, corte láser) |

## Uso

Abre el enlace de arriba o descarga `index.html` y ábrelo localmente — no requiere conexión a internet una vez cargado.

## Tecnología

HTML + CSS + JavaScript puro, sin dependencias externas salvo las fuentes (IBM Plex Mono e Inter vía Google Fonts). Compatible con modo claro y oscuro del sistema.
